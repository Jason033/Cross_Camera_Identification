REID / 研究地圖總覽特徵融合攝影機差異資料集
CAMERA DOMAIN / NORMALIZATION

攝影機改變了什麼？正規化能補到哪裡？

同一個人進入不同鏡頭時，像素外觀、可見部位與座標都可能改變。正規化的目標是減少「鏡頭造成的差異」，保留「人的差異」；它不能憑空補回遮住的身體、失焦細節或未拍到的背面。

01 / 光與色

曝光、白平衡、夜視

自動曝光、不同色溫、紅外線與壓縮會改變顏色和對比。制服色差可能是鏡頭差異，不是身分差異。

02 / 距離與解析度

人物像素數不同

遠距人物只有數十像素高時，徽章、鞋型等細節消失；放大只增加像素，不會恢復原始細節。

03 / 角度與透視

正面、側面、背面

可見區域與身體比例投影會變。側面看不到胸前標記，透視也會讓近側肢體看起來較大。

04 / 時間與場景

光線、天氣、時段

白天/夜間、陰影、雨霧、補光狀態可能隨時間變動；畫面時間戳偏差還會破壞跨鏡頭先後關係。

四層處理：從像素到最後分數

以下例子用同一個人出現在 A、B 鏡頭；每一層處理不同問題。實務上應按資料切分擬合參數，只用訓練集估計，避免把測試資訊洩漏進模型。

1 · 影像校正光色、裁切與尺度2 · 座標映射地面位置、對齊時間3 · 特徵降低鏡頭域偏差4 · 分數校準尺度並依品質加權輸出匹配、未知或待確認
層次示例做法小例子主要限制
影像正規化
pixel / crop		固定人物框比例與輸入尺寸；訓練時用亮度、色溫、對比增強；可比較灰世界白平衡、直方圖/色彩轉換。A 的白牆使制服偏藍，B 的黃燈使制服偏黃。做白平衡後色偏縮小，模型較不會把整體色溫當成身分線索。色彩轉換不能修復剪影、過曝或紅外線缺失；過度增強會把真實制服色差抹平。對比/直方圖處理需避免放大噪聲。
座標正規化
geometry / time		相機標定、地面平面單應性映射；依影格率/時間戳同步，使用跨鏡頭轉移時間分佈與可達區域。同一通道上的位置由 A 影像像素 (420,360) 與 B 的 (180,210) 映到地面座標後，可能都落在走道位置 (6.2m, 3.1m)；候選轉移時間例如 8–25 秒。單應性只近似平坦地面，斜坡、多層樓、遮擋與鏡頭移動會失效。時間窗是先驗而非身分證明；人可停留、折返或走不同路徑。
特徵正規化
embedding		L2 單位化；以訓練資料做相機域對抗/風格增強、域自適應，或學習鏡頭不變表徵。比較視角條件式模型。兩個 512 維向量先除以各自長度，避免向量大小主導距離；再以餘弦相似度比較。只用特徵正規化不能自動消除視角造成的語意變化。需要涵蓋各相機、視角、照明的訓練樣本；未知鏡頭仍會有域差。若硬追求相機不變，可能連真正有辨識力的線索一起消掉。
分數正規化
decision		按相機對/模型用驗證集估計分數分佈；轉為 z-score、校準機率或分位數；結合品質與時空可行性，設定拒判門檻。相同人物 A-B 外觀分數 0.62，但 B 很模糊；校準後並非直接解讀成 62% 機率。降低模糊影像分支權重後，需再由其他證據判斷或列待確認。校準依賴代表性的驗證集；新鏡頭、新季節或不同人群會漂移。閾值取決於錯認/漏認成本，不能只用一組全域閾值保證可靠。
分數小算例（純示意）

品質加權，不等於機率

S = (q_app·s_app + q_pose·s_pose + q_time·s_time) / (q_app + q_pose + q_time)
A↔B：s = (0.62, 0.78, 0.90), q = (0.35, 0.70, 0.80)
S ≈ 0.80（只有經驗證校準後，才可轉成決策信心）

影像低清時 q_app 下降；若時間戳不可靠，q_time 也應下降。還需設定「低於門檻就不配對」及「多候選接近時待確認」規則。

建議比較順序

先定位問題再加正規化

固定人員切分，建立未處理基準；逐項加入影像、座標、特徵、分數處理，做消融比較。按攝影機對、日夜、距離/人物像素高度、視角分桶，分別記錄 Rank-1/mAP、錯配、FAR/FRR 與拒判率。

不要只看整體平均：改善日間近景但讓夜間遠景錯配增加，不能算穩定提升。

重要區分：單攝影機「跨視角」多半是同一成像管線中，人物轉身或在畫面中改變方位；它能測視角魯棒性，卻未測到不同鏡頭的色彩響應、鏡頭高度、解析度、時鐘與場景差。實際跨攝影機必須按鏡頭分開訓練/測試或留出未見鏡頭，並驗證相機對的時間與位置關係。單攝影機有效，不代表跨攝影機已解決。

建議流程：校時與標定 → 人物品質評估 → 四層正規化/特徵抽取 → 相機對候選篩選 → 校準與融合 → 匹配或拒判 → 按鏡頭、視角、畫質回看錯例。
