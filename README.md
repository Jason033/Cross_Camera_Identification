# 同制服跨攝影機辨識｜技術探索地圖

高度相似制服環境下的跨攝影機人員再辨識（Cross-Camera Person Re-Identification）第一階段文獻研究，整理成以圖表與互動為主的網頁。

## 怎麼開

**線上：** 若已開啟 GitHub Pages，網址為 `https://jason033.github.io/Cross_Camera_Identification/`。

**離線（任何電腦）：**
1. 在 GitHub 頁面按 **Code → Download ZIP**
2. 解壓縮（保持資料夾結構，`index.html` 要和 `assets/` 在同一層）
3. 直接雙擊 `index.html`，用 Chrome / Edge / Firefox 開啟即可

不需要安裝任何東西、不需要網路、不需要架伺服器。網站不載入任何線上字型、程式庫或圖片；只有「參考文獻」裡的論文連結需要網路。

## 閱讀須知

- 圖中人物、特徵點、分數分布都是**程式產生的教學示意**，不是實驗結果。
- 每個主張都標了證據等級：■ 文獻證實　◧ 合理推論　⬚ 待驗證。
- 2026 年的資料集（Industrial-Gait、ConstrID、FG-PersonX、MMGait）皆已確認存在；標「部分待核對」者，部分數字取自前次研究報告。
- 授權欄位是研究時讀到的狀態，正式採用前請法務確認。

## 檔案結構

```
index.html            所有章節的文字與版面
assets/style.css      樣式
assets/js/data.js     第一輪資料：論文、資料集、線索、證據
assets/js/research.js 第二輪研究：方法總表、證據卡、系統、驗證、品控資料
assets/js/geom.js     攝影機幾何（可行性計算器）
assets/js/person.js   程序化 3D 人體步行模型（Drillis & Contini 節段比例）
assets/js/util.js     SVG、提示框、統計小工具
assets/js/ch-*.js     各章節的互動圖
assets/js/app.js      章節切換（用網址 #，file:// 也能用）
```

全部為原生 HTML / CSS / JavaScript，沒有建置步驟。舊版網站保留在 `legacy/` 資料夾（網址 `/legacy/`），也在 git 歷史中（commit `477b93f`）。
