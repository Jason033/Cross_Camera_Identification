# 同制服跨攝影機辨識｜技術探索地圖

高度相似制服環境下的跨攝影機人員再辨識（Cross-Camera Person Re-Identification）第一階段文獻研究，整理成以圖表與互動為主的網頁。

## 怎麼開

**線上：** 若已開啟 GitHub Pages，網址為 `https://jason033.github.io/Cross_Camera_Identification/`。

**離線（任何電腦）：**
1. 在 GitHub 頁面按 **Code → Download ZIP**
2. 解壓縮（保持資料夾結構，`index.html` 要和 `assets/` 在同一層）
3. 直接雙擊 `index.html`，用 Chrome / Edge / Firefox 開啟即可

不需要安裝任何東西、不需要網路、不需要架伺服器。網站不載入任何線上字型、程式庫或圖片；只有「參考文獻」裡的論文連結需要網路。

## 內容

**專案目標**：國軍版的「天眼」——利用營區既有的一般光學監視器，自動重建「誰、在什麼時間、經過哪些地點」。用途：重建每人移動路徑、事後查詢特定人員、標出名冊外的人。

**第一階段範圍**：同一畫面 5 人以內（不含部隊行進）；白天與一般照明（夜間、雨天看不清時允許「無法判定」）；迷彩服＋小帽、鋼盔、夏季捲袖、冬季外套、運動服，**同一天內會換裝**；攝影機配置未知，以常見路邊監視器為參考；門禁刷卡只當輔助證據（可能被代刷）。

文件的主幹依系統的七個步驟組織：攝影機與偵測 → 追蹤成片段 → 身分線索特徵 → 換成證據（融合）→ 時空約束 → 分群 → 比對名冊（刷卡輔助）。每一步依序是：路線地圖（這一步有哪幾種做法與取捨）→ 主要方法（怎麼運作：輸入、處理、訓練、輸出；在路邊俯角、換裝、5 人交錯、CPU 算力、軍用授權下的優缺點）→ 其他方法 → 我們的選擇（單一選擇、起始設定、通過條件）。各方法的程式碼、權重、輸入格式與第一步怎麼試收在可展開的「實作資訊」裡。讀者設定為剛接觸這個領域的工程師：文中第一次出現的專有名詞有虛線底線，滑過即可看解釋。

## 閱讀須知

- 圖中人物、特徵點、分數分布都是**程式產生的教學示意**，不是實驗結果。服裝依國軍常見樣式繪製，配色為近似值。
- 每個主張都標了證據等級：■ 文獻證實　◧ 合理推論　⬚ 待驗證。
- 2026 年的資料集（Industrial-Gait、ConstrID、FG-PersonX、MMGait）皆已確認存在；標「部分待核對」者，部分數字取自前次研究報告。
- 授權欄位是研究時讀到的狀態，正式採用前請法務確認。

```
index.html            所有章節的文字與版面
assets/style.css      樣式
assets/js/data.js     第一輪資料：論文、資料集、線索、證據
assets/js/steps.js    第 2 章的內容：七步的候選方法、判定與實作資訊（改內容主要改這裡）
assets/js/ch-steps.js 依 steps.js 產生方法卡片、第一版元件表與總覽摘要
assets/js/others.js   第 3 章的內容：架構類型與各系統的流程、可借用與不適合之處（改內容主要改這裡）
assets/js/ch-others.js 依 others.js 產生第 3 章的架構卡、對照表與系統卡片
assets/js/flowplay.js 第 3 章每張卡片的「動畫說明」播放器：共通步驟用共用場景快速帶過；各系統的特色步驟（others.js 中以 x_ 開頭的場景）用專屬圖解放慢說明
assets/js/methodplay.js 第 2 章每張方法卡的動畫：輸入 → 處理（各方法專屬圖解）→ 訓練 → 輸出（標出維度、成績、算力）→ 在我們的條件下（闖五關）；其他方法為專屬概念圖 → 判定
assets/js/cmpplay.js  第 2 章各組的「並排比較」動畫：原理一覽、文獻成績、營區情境（推論）、需要什麼與授權、條件矩陣
assets/js/ourplay.js  第 4 章的動畫說明：第一版系統從頭到尾、七步各自的細部設定、身分四層、交付成果（場景數字與 steps.js 的起始設定一致）
assets/js/ch-server.js 伺服器等級與算力估算（單位成本與依據寫在檔案開頭）
assets/js/glossary.js 名詞表（總覽頁與內文的名詞解釋）
assets/js/research.js 第二輪研究：方法總表、證據卡、系統、驗證、品控資料
assets/js/geom.js     攝影機幾何（可行性計算器）
assets/js/person.js   程序化 3D 人體步行模型（Drillis & Contini 節段比例）
assets/js/util.js     SVG、提示框、統計小工具
assets/js/viz-kit.js  第 3、4 章共用：人物中間表示（剪影、骨架、3D 體型）與玩具特徵計算
assets/js/ch-*.js     各章節的互動圖
assets/js/ch-intro.js 總覽頁的系統全景與名詞、第 1 章的評分入門圖
assets/js/app.js      章節切換（用網址 #，file:// 也能用）、自動圖號、章內目錄、名詞解釋
```

全部為原生 HTML / CSS / JavaScript，沒有建置步驟。更早的版本保留在 git 歷史中（例如 commit `477b93f`、`2562b2e`）。
