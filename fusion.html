看圖理解 01 · 特徵串接

兩條分支的向量怎麼變成一條？

假設兩個分支都已對同一段人物軌跡抽出特徵。示意只保留少量維度，真實模型通常是數百維，並會先做向量正規化。

為什麼同維度串接可行？
每筆資料都依相同順序放入 768 個外觀值與 256 個步態值；因此兩條軌跡可逐維比較。
正規化解決什麼？
向量長度不再單純受數值尺度影響。若要讓某分支更有影響力，還需明確加權、投影或用資料學習。

維度數字取自教學假設，實際輸出維度需查模型設定。此圖說明資料如何排成向量，不宣稱辨識效果。

看圖理解 02 · 分數融合

同一套分數，如何合併兩個線索？

假設每個分支已在驗證資料校準成「相似度 0–1」，再比較 query 與兩位 gallery 候選。以下分數全是假設，只用來示範名次怎麼變。

這個例子表達的技術意思：融合可以改變候選排序，因為它綜合多個分支的證據。若兩種模型的分數未校準到可比較尺度，直接平均就沒有可靠解釋；0.75 也不是「75% 是同一人」。

05 / FUSION LAB

融合：讓互補線索一起工作

同制服讓顏色與款式的辨識力變弱；外觀細節、步態、輪廓、骨架與時空線索可能互補。融合不是把所有數字直接相加：先確認特徵尺度，再決定在特徵層或分數層合併。

各分支抽特徵正規化與品質檢查特徵／分數融合候選排序或拒判
01 / FEATURE FUSION · CONCAT

先正規化，再串接

假設只為說明計算：外觀分支向量為 [3, 4]，步態分支為 [0, 10]。兩邊量級不同；若跨樣本差異也同樣偏大，未處理就串接可能讓步態分支在距離計算中占較大影響。

L2 正規化： x̂ = x / ‖x‖₂
外觀 [3,4] → [0.60, 0.80]
步態 [0,10] → [0.00, 1.00]

串接後成為四維表示：

0.600.800.001.00
z = [x̂外觀 ; x̂步態] = [0.60, 0.80, 0.00, 1.00]

若希望分支權重為 α 與 β（α+β=1），可用 z=[√α·x̂外觀 ; √β·x̂步態]，使各段對平方距離的貢獻按權重縮放。上例數值皆為教學假設，並非實驗結果。

02 / PAIR MATCHING

串好以後怎麼比對？

假設兩段軌跡分別來自鏡頭 A 與 B；兩邊各自產生相同順序與維度的融合向量。

A = [外觀 A ; 步態 A]
B = [外觀 B ; 步態 B]
距離 d(A, B) = ‖A − B‖₂

將 A 與每一個候選人計算距離後排序。距離較小代表在這個特徵空間較接近；閾值需用獨立驗證資料校準，不能直接當成同一人的機率。

03 / SCORE FUSION

各自比對，再融合分數

每個模型分別產生 query 與候選人的相似度，接著校準並合併，例如加權和、排名融合或學習一個小型融合器。

分支模型 → s外觀, s步態, s輪廓
校準分數 → s* = Σ wᵢ · sᵢ

適合：已有可用的獨立模型、希望快速建立多模態基準，或需要容易檢查各線索貢獻的系統。

局限：不同模型的分數分布和尺度可能不同；只融合最終分數，也較難學到跨模態的細部互動。

04 / ATTENTION & GATING

由輸入內容決定線索重要性

Attention：讓模型依當前影像／軌跡，學習不同時間片段或模態之間的關聯與權重。適合線索互動豐富且有足夠訓練資料的情況。

Gating：以品質或特徵計算每個分支的門值，例如遮擋嚴重時降低外觀分支，骨架不完整時降低姿態分支；輸出加權特徵或分數。

gᵢ = sigmoid(MLP(品質、特徵))
融合 = Σ gᵢ · xᵢ （再正規化）

局限：注意力權重不等同可信度解釋；gate 可能學到資料偏差，仍要用缺失、遮擋、低解析與跨鏡頭切分驗證。

05 / MISSING BRANCH

某條線索缺失時怎麼辦？

不要把「沒有觀測」當成相似度 0。用可用分支的權重重新正規化；若所有分支都低品質或缺失，輸出待確認／未知。

A = 可用分支集合
s = Σᵢ∈A wᵢsᵢ / Σᵢ∈A wᵢ
例：臉不可見 → 臉部分支移出 A，其他分支權重按剩餘總和重算

更完整的做法是訓練時加入模態缺失與品質變化，並記錄每次比對實際使用了哪些分支。缺失處理策略需和門檻校準一起評估。

實務順序：先做單分支基準 → 對齊相似度尺度或正規化特徵 → 比較簡單加權與分數融合 → 再試品質感知 gate／attention。以同一資料切分比較錯配案例、Rank-1／mAP，以及未知人 FAR／FRR；每個提升都要由實際測試支持。
